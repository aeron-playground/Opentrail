## Adding a record

Copy the template into a new file named with the next number, like `0018-short-name.mdx`, add a
row to the table above, and open a pull request. A change that would break the public API always
needs a record.

```mdx title="0018-short-name.mdx"
---
title: "ADR 0018: A short name for the decision"
description: One line that says what was decided.
---

## Status

Accepted on 2026-10-01.

## Context

The problem, and what makes it hard.

## Decision

What we decided, in plain words.

## Consequences

What gets easier, what gets harder, and when to look at it again.
```
